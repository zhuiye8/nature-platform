## 二、业务流程

```
创建客户 → 创建合同 → 合同审核 → 合同归档
                                    ↓
                              创建项目登记 → 审核项目登记 → 公安登记
                                                              ↓
                                                         现场测评
                                                    （上传测评文件+成果）
                                                              ↓
                                            ┌─── 技术审核 ───┐
                                            │                 │
                                            │   内容审核(3路)  │
                                            │                 │
                                            └────────────────┘
                                                              ↓
                                                    报告编制任务分配
                                                              ↓
                                                      报告编制上传
                                                              ↓
                                                       最终审核
                                                              ↓
                                                       材料归档
                                                              ↓
                                                        项目完成
```

## 三、各步骤操作说明

### 1. 创建客户 → 创建合同 → 提交审核
**操作人**：销售

1. 左侧菜单「客户管理」→ 新建客户
2. 左侧菜单「合同管理」→ 新建合同 → 选择客户 → 填写系统明细和服务年份 → 保存
3. 上传合同文件（列表页点击上传）
4. 点击「提交审核」

> 合同名称会自动生成，无需手动填写

### 2. 审核合同
**操作人**：谢宝建（部门经理）

待办中心 → 审核任务 → 点击「审核」→ 通过或驳回

### 3. 合同归档
**操作人**：张渝松（商务）

合同管理 → 找到已通过的合同 → 点击「归档」→ 填写归档信息 → 提交

### 4. 创建项目登记
**操作人**：销售

左侧菜单「项目登记」→ 新建项目登记 → 选择已归档的合同 → 选择年度 → 保存 → 编辑系统明细 → 提交

### 5. 审核项目登记
**操作人**：谢宝建（部门经理）

待办中心 → 审核任务 → 选择测评师 → 通过

### 6. 公安登记
**操作人**：宋秀珍

公安登记 → 新建 → 选择关联项目 → 选择项目经理 → 保存 → 进入详情上传扫描件 → 编辑登记信息 → 完成登记

### 7. 现场测评
**操作人**：项目经理 + 测评师

测评实施 → 找到项目 → 查看
- 测评师上传「测评文件」
- 项目经理上传「测评成果」→ 点击「发起质量审核」

### 8. 技术审核
**操作人**：陈彦文 或 陈新东（系统自动分配，回避项目组成员）

待办中心 → 审核任务 → 查看测评成果 → 选择：
- **通过** → 进入内容审核
- **复核** → 项目经理整改测评成果后重新提交

### 9. 内容审核（三路并行）
**操作人**：系统自动分配三人

| 方向 | 候选人 |
|------|--------|
| 技术 | 王寅森、杨泉森 |
| 管理 | 宋秀珍、王霞莉 |
| 网络 | 陈彦文、陈新东 |

全部通过 → 进入报告编制分配

> 任一人选择「复核」→ 三人全部需要重新审核

### 10. 报告编制分配
**操作人**：宋秀珍（报告分配人）

待办中心 → 选择编制人 → 通过

### 11. 报告编制
**操作人**：被分配的编制人（李旭、卢雨欣、宋秀珍、耿宇）

报告管理 → 找到项目 → 上传编制报告文件 → 通过

### 12. 最终审核
**操作人**：谢宝建（部门经理）

待办中心 → 审核任务 → 选择：
- **通过** → 进入材料归档
- **复核** → 编制人修改报告后重新提交
- **驳回** → 回到现场测评，项目经理重新发起（新一轮）

### 13. 材料归档
**操作人**：汤婷（归档员）+ 项目经理 + 销售 协助

材料归档 → 找到项目 → 逐项勾选卷内清单 → 上传扫描件 → 填写存放位置 → 提交归档

> 项目经理和销售也可以进入归档详情上传自己手里的材料扫描件

## 四、常用操作提示

| 场景 | 说明 |
|------|------|
| 收到通知 | 页面右上角铃铛图标查看，点击可跳转 |
| 被驳回 | 项目详情页顶部会显示红色驳回原因 |
| 待整改 | 测评实施列表会显示红色「待整改」标签 |
| 重新提交 | 修改测评成果后，在测评详情页点击「重新提交」 |
| 审核意见 | 所有审核节点的详情页都有「审核意见历史」可查看 |
