## 二、角色权限体系

### 池化审批说明
部分审批节点采用**池化（pool）审批**模式：该角色下所有启用的成员都能看到待审任务并操作，先审先得（原子锁防并发）。

| 节点 | 审批角色 | 模式 | 说明 |
|------|---------|------|------|
| 合同审核 | 部门经理 | 池化 | 所有部门经理可见可审 |
| **项目登记准入确认**（`DEPT_REVIEW`，仅合同未归档） | 部门经理 | 池化 | 仅确认是否允许登记进场，**不分配人员**；通过后自动进入项目主管审核 |
| **项目登记审核并分配**（`DIRECTOR_REVIEW`） | 项目主管 | 池化 | **所有项目主管可见可审**；审批时单选 PM + 多选测评师；合同已归档时直接进入此节点（跳过部门经理） |
| 合同归档 | 商务 | 池化 | 认领后处理 |
| 材料归档 | 归档员 | 池化 | 销售/PM 可进入详情上传原始材料（文件池） |
| 技术审核 | 技术审核人 | **单人**（规则表分配，回避项目组） | 自动分配，不池化 |
| 内容审核 | 三路并行 | **单人**（规则表分配，回避项目组） | 三个方向各一人 |
| 报告编制 | 报告编制人 | **指定** | 由报告分配人指定 |

### 审批入口统一
**所有审批都在 `TaskDetail`（任务详情页）进行**，不再使用弹窗：
- 待办任务列表点击"审核" → 进入 `/workflow/task/:taskId`
- 项目详情页点击"审批" → 同样跳转到 `/workflow/task/:taskId`
- 审批页面根据节点 `nodeKey` 动态渲染不同表单（备注/PM/测评师/编制人等）

### 角色成员管理
系统管理 → 角色管理 → 点击"成员"按钮可以查看/添加/移除/排序角色成员。成员排序影响自动分配优先级（序号越小越优先）。

## 三、业务流程

```
创建客户 → 新建合同组 → 组内创建合同 → 上传合同文件+文件说明 → 提交审核
     （联系人一对多）   （归组管理）    （委托书/收款/付款）
                                                    ↓
                                        合同审核（部门经理池化）
                                                    ↓（通过，自动生成编号）
                                          合同归档（商务认领）
                                                    ↓
                     创建项目登记（只要合同通过即可，不再要求完全归档）
                     → 系统明细自动继承客户信息 → 提交
                                                    ↓
                                ┌─ 合同未归档: 部门经理确认准入（DEPT_REVIEW）
                                │              ↓（通过）
                                └─ 项目主管审核并分配 PM + 测评师（DIRECTOR_REVIEW，池化）
                                   → 自动生成系统编号（合同编号-年份序号）
                                                    ↓
                                   公安登记（自动创建，上传扫描件即完成）
                                                    ↓
                                              现场测评
                                         （上传测评文件+成果）
                                                    ↓
                                    ┌─── 技术审核 ───┐
                                    │                 │
                                    │   内容审核(3路)  │
                                    │                 │
                                    └────────────────┘
                                                    ↓
                                          报告编制任务分配
                                                    ↓
                                            报告编制上传
                                                    ↓
                                             最终审核
                                                    ↓
                                             材料归档
                                                    ↓
                                              项目完成
```

## 四、各步骤操作说明

### 1. 创建客户
**操作人**：销售

1. 左侧菜单「客户管理」→ 新建客户
2. 填写客户名称、行业（分组下拉）、区域（省市区级联，江苏省/扬州市优先）
3. 添加联系人（支持多个）：姓名、电话、职务、备注
4. 保存

### 2. 创建合同组 → 创建合同 → 提交审核
**操作人**：销售

1. 左侧菜单「合同管理」→ 新建合同组 → 输入组名（如中标项目名称）
2. 在合同组行点击「新增合同」→ 选择合同分类（委托书/收款合同/付款合同）
3. 选择客户 → 联系人自动加载（下拉选择）→ 统一信用代码自动展示
4. 填写服务内容、合同类型（自主/直接合作/间接合作）、签单销售、合作方
5. 填写财务信息：付款金额、付款信息、付款单位、发票类型、税率、付款方式
6. 添加系统明细（至少一条）和服务年份
7. 保存 → 上传合同文件（支持多个）和合同文件说明（必须上传）
8. 点击「提交审核」

> 合同名称和编号会在审核通过后自动生成
> 编号格式：YZDZR-{服务内容代码}-{年份}-{序号}，如 YZDZR-DBCP-26-0001
> 跟单销售与创建者享有同等操作权限

### 3. 审核合同
**操作人**：谢宝建等（所有部门经理，池化审批）

待办中心 → 审核任务 → 查看合同信息（含合同组关联合同状态）→ 通过或驳回

> 合同审核为池化模式，所有部门经理可见，先审先得

### 4. 合同归档
**操作人**：张渝松（商务）

待办中心 → 认领合同归档任务 → 填写归档信息（签订时间、文件份数、存放位置）→ 上传扫描件 → 提交

> 归档任务为 pool 模式，所有商务角色都会收到通知，认领后处理

### 5. 合同财务（回款管理）
**操作人**：李青（财务）

左侧菜单「财务管理」→「合同财务」→ 查看审核通过的合同 → 点击「编辑回款」→ 设置回款状态和回款备注

> 财务角色只能看到已通过审核的合同
> 回款操作需要 `contract:update_financial` 权限（已分配给财务角色）

### 6. 创建项目登记
**操作人**：销售

1. 左侧菜单「项目登记」→ 新建项目登记 → **选择已通过审核的合同**（不再要求完全归档）→ 选择年度
2. 保存后进入编辑页 → 填写系统明细：
   - 新增系统明细时**自动继承客户信息**：被测单位名称、联系人、联系电话、地址、备案区域、备案机关
   - 备案机关统一为"市公安局"格式（如"扬州市公安局"，不再有"分局"后缀）
   - 安全等级（一级~五级）
   - 备案证明（必须上传）、证明编号、出具时间
   - 备案表、定级报告（选填）
3. 所有系统明细必填字段填写完整后 → 提交审核

> **同一合同同一年度可以创建多个项目登记**（支持分批登记：部分系统备案证明先到先登记）
> 系统编号在多次登记间累加，不会重复

### 7. 审核项目登记（两步走）

**Step A — 部门经理确认准入（仅合同未归档时）**

**操作人**：谢宝建等（所有部门经理，池化）

1. 待办中心 → 审核任务 → 进入任务详情页
2. 查看项目信息、关联合同、系统明细
3. **仅确认准入**，不需要分配人员；点击"通过"或"驳回"

> 若**合同已完全归档**，提交时会直接跳过此步进入 Step B

**Step B — 项目主管审核并分配**

**操作人**：陈彦文等（所有项目主管，池化）

1. 待办中心 → 审核任务 → 进入任务详情页
2. 审批区显示：
   - **项目经理**（radio 单选）：候选来自高级 + 中级测评师，按级别分组
   - **测评师**（checkbox 多选）：候选来自 3 级测评师，按级别分组
3. 选择完毕后点击"通过"

> **审批通过后自动生成系统编号**：
> - 格式：`{合同编号}-{年份后2位}{序号2位}`
> - 例如：`YZDZR-DBCP-26-0001-2601`（第 1 个系统）、`...-2602`（第 2 个）
> - 同一合同同一年度的多次项目登记共享计数器（如第一次有 2 个系统编到 02，第二次从 03 开始）
> - 不同年度从 01 重新计数

> **项目经理和测评师分配关系**：
> - 分配完成后，PM 和测评师会写入 `project_member` 表
> - 从此刻起，这些成员可以在"项目登记列表"看到自己被指派的项目（其他项目看不到）
> - 在"测评实施列表"也能看到并参与现场测评

### 8. 公安登记
**操作人**：宋秀珍（公安登记专员）

> **自动创建**：项目登记审批通过后自动创建公安登记记录，**无需手动绑定**

1. 公安登记列表 → 自动出现待登记项目
2. 点击「查看」进入详情页 → **只读展示**项目完整信息（项目信息、系统明细、项目成员）
3. 系统明细以**表格形式**展示（项目编号、系统名称、备案证明编号、安全等级、备案机关、被测单位名称、附件），点击"详情"按钮可弹窗查看完整信息
4. 查看/下载信息后前往公安机关办理
5. 上传电子扫描件（PDF，支持**多个文件增删**）
6. **上传首个文件后自动完成**，工作流自动推进到现场测评（无需手动点"完成"）

> 每条公安登记支持**导出 Excel**（14 列，基于官方模板，含"导入说明" sheet）
> 文件名格式：`{申请单名称}-公安登记-{导出日期}.xlsx`
> 列表显示项目经理和手机号

### 9. 现场测评
**操作人**：项目经理 + 测评师

测评实施 → 找到项目 → 查看
- 测评师上传「测评文件」
- 项目经理上传「测评成果」→ 点击「发起质量审核」

### 10. 技术审核
**操作人**：陈彦文 或 陈新东（系统自动分配，回避项目组成员）

待办中心 → 审核任务 → 查看测评成果 → 选择：
- **通过** → 进入内容审核
- **复核** → 项目经理整改测评成果后重新提交

> 技术审核为**规则表单人分配**，自动回避项目组成员，不是池化

### 11. 内容审核（三路并行）
**操作人**：系统自动分配三人

| 方向 | 候选人 |
|------|--------|
| 技术 | 王寅森、杨泉森 |
| 管理 | 宋秀珍、王霞莉 |
| 网络 | 陈彦文、陈新东 |

全部通过 → 进入报告编制分配

> 任一人选择「复核」→ 三人全部需要重新审核
> 内容审核为**规则表单人分配**，回避项目组成员，不是池化

### 12. 报告编制分配
**操作人**：宋秀珍（报告分配人）

待办中心 → 选择编制人 → 通过

### 13. 报告编制
**操作人**：被分配的编制人（李旭、卢雨欣、宋秀珍、耿宇）

报告管理 → 找到项目 → 上传编制报告文件 → 通过

> 报告编制任务为**指定分配**（由报告分配人在上一步指定），不是池化

### 14. 最终审核
**操作人**：谢宝建（部门经理）

待办中心 → 审核任务 → 选择：
- **通过** → 进入材料归档
- **复核** → 编制人修改报告后重新提交
- **驳回** → 回到现场测评，项目经理重新发起（新一轮）

### 15. 材料归档
**操作人**：汤婷（归档员）+ 项目经理 + 销售 协助

材料归档 → 找到项目 → 逐项勾选卷内清单 → 上传扫描件 → 填写存放位置 → 提交归档

> 项目经理和销售也可以进入归档详情上传自己手里的材料扫描件

## 五、文件预览与水印

- 所有详情页的附件文件（备案证明、扫描件等）**点击文件名在新标签页预览**
- 预览时**自动叠加水印**（用户名 + 日期时间），防止截图泄漏
- 图片格式（JPG/PNG/GIF/WEBP）和 PDF 格式支持预览
- 不支持预览的格式（ZIP 等）点击直接下载
- 下载原文件不含水印

## 六、系统管理

### 角色成员管理
系统管理 → 角色管理 → 每个角色行有"成员"按钮：
- 查看角色下所有用户
- 添加/移除用户
- 上下移动调整排序（排序影响工作流自动分配的优先级）

### 用户管理
系统管理 → 用户管理：

**列表字段**：用户名 / 姓名 / 手机号 / 状态 / **证书编号**（掩码：前4 + ****** + 后4） / **角色**（中文名，多标签） / 钉钉绑定 / 创建时间 / 操作

**筛选**：用户名/姓名/手机号 关键字 + 证书编号 模糊查询

**证书编号展示**：
- 默认掩码显示：`2500********1331`
- 点击眼睛图标 👁 切换显示完整编号
- 长度 < 8 时全掩码

**新建/编辑用户**：
- 用户名格式校验（字母/数字/下划线，3-32位），失焦时实时查重
- 密码：至少 8 位 + 英文 + 数字（DTO + Form 两层校验）
- 可选填证书编号（最长 64 字符）

**重置密码**：
- 点击"重置密码"按钮 → 后端自动生成临时密码 `Nature@2026`
- 弹窗显示临时密码（红色加粗），管理员告知用户
- 用户用临时密码登录后**强制修改密码**（`mustChangePwd=true`）

**分配角色**：点击"角色"按钮 → 勾选角色 → 确定

> 测评师分级由"分配角色"完成：给用户勾选 `senior_assessor` / `middle_assessor` / `junior_assessor`（三者权限一致，仅影响 PM 候选范围）

### 注册平台管理
系统管理 → 注册平台 → 支持 CRUD + Excel 导入导出 + 密码遮罩
- 列表显示备注列（长文本自动换行）
