## 二、业务流程

```
创建客户 → 新建合同组 → 组内创建合同 → 上传合同文件+文件说明 → 提交审核
     （联系人一对多）   （归组管理）    （委托书/收款/付款）
                                                    ↓
                                          合同审核（部门经理）
                                                    ↓（通过，自动生成编号）
                                          合同归档（商务认领）
                                                    ↓
                                          创建项目登记 → 填写系统明细 → 提交
                                                    ↓
                                      项目登记审核（项目主管）
                                      → 分配项目经理 + 测评师
                                                    ↓
                                              公安登记
                                                    ↓
                                              现场测评
                                         （上传测评文件+成果）
                                                    ↓
                                    ┌─── 技术审核 ───┐
                                    │                 │
                                    │   内容审核(3路)  │
                                    │                 │
                                    └────────────────┘
                                                    ↓
                                          报告编制任务分配
                                                    ↓
                                            报告编制上传
                                                    ↓
                                             最终审核
                                                    ↓
                                             材料归档
                                                    ↓
                                              项目完成
```

## 三、各步骤操作说明

### 1. 创建客户
**操作人**：销售

1. 左侧菜单「客户管理」→ 新建客户
2. 填写客户名称、行业（分组下拉）、区域（省市区级联，江苏省/扬州市优先）
3. 添加联系人（支持多个）：姓名、电话、职务、备注
4. 保存

### 2. 创建合同组 → 创建合同 → 提交审核
**操作人**：销售

1. 左侧菜单「合同管理」→ 新建合同组 → 输入组名（如中标项目名称）
2. 在合同组行点击「新增合同」→ 选择合同分类（委托书/收款合同/付款合同）
3. 选择客户 → 联系人自动加载（下拉选择）→ 统一信用代码自动展示
4. 填写服务内容、合同类型（自主/直接合作/间接合作）、签单销售、合作方
5. 填写财务信息：付款金额、付款信息、付款单位、发票类型、税率、付款方式
6. 添加系统明细（至少一条）和服务年份
7. 保存 → 上传合同文件（支持多个）和合同文件说明（必须上传）
8. 点击「提交审核」

> 合同名称和编号会在审核通过后自动生成
> 编号格式：YZDZR-{服务内容代码}-{年份}-{序号}，如 YZDZR-DBCP-26-0001
> 跟单销售与创建者享有同等操作权限

### 3. 审核合同
**操作人**：谢宝建（部门经理）

待办中心 → 审核任务 → 查看合同信息（含合同组关联合同状态）→ 通过或驳回

### 4. 合同归档
**操作人**：张渝松（商务）

待办中心 → 认领合同归档任务 → 填写归档信息（签订时间、文件份数、存放位置）→ 上传扫描件 → 提交

> 归档任务为 pool 模式，所有商务角色都会收到通知，认领后处理

### 5. 合同财务（回款管理）
**操作人**：李青（财务）

左侧菜单「财务管理」→「合同财务」→ 查看审核通过的合同 → 点击「编辑回款」→ 设置回款状态和回款备注

> 财务只能在此页面编辑回款信息，合同详情页为只读

### 6. 创建项目登记
**操作人**：销售

1. 左侧菜单「项目登记」→ 新建项目登记 → 选择已归档的合同 → 选择年度
2. 保存后进入编辑页 → 填写系统明细：
   - 备案区域（省市区级联）→ 备案机关自动生成（可手动修改）
   - 安全等级（一级~五级）
   - 被测单位信息（名称、行业、联系人、电话、地址）
   - 备案证明（必须上传）、证明编号、出具时间
   - 备案表、定级报告（选填）
3. 所有系统明细必填字段填写完整后 → 提交审核

### 7. 审核项目登记
**操作人**：陈彦文（项目主管）

待办中心 → 审核任务 → 选择项目经理（单选）→ 选择测评师（多选）→ 通过

> 项目主管替代原来的部门经理负责项目登记审核
> PM 和测评师统一在此步骤分配

### 8. 公安登记
**操作人**：宋秀珍

公安登记 → 新建 → 选择关联项目 → 编辑登记信息：
- 登记编号（必填）
- 备案区域（级联选择）→ 备案机关自动生成
- 联系人、联系电话（必填）
- 上传扫描件 → 完成登记

### 9. 现场测评
**操作人**：项目经理 + 测评师

测评实施 → 找到项目 → 查看
- 测评师上传「测评文件」
- 项目经理上传「测评成果」→ 点击「发起质量审核」

### 10. 技术审核
**操作人**：陈彦文 或 陈新东（系统自动分配，回避项目组成员）

待办中心 → 审核任务 → 查看测评成果 → 选择：
- **通过** → 进入内容审核
- **复核** → 项目经理整改测评成果后重新提交

### 11. 内容审核（三路并行）
**操作人**：系统自动分配三人

| 方向 | 候选人 |
|------|--------|
| 技术 | 王寅森、杨泉森 |
| 管理 | 宋秀珍、王霞莉 |
| 网络 | 陈彦文、陈新东 |

全部通过 → 进入报告编制分配

> 任一人选择「复核」→ 三人全部需要重新审核

### 12. 报告编制分配
**操作人**：宋秀珍（报告分配人）

待办中心 → 选择编制人 → 通过

### 13. 报告编制
**操作人**：被分配的编制人（李旭、卢雨欣、宋秀珍、耿宇）

报告管理 → 找到项目 → 上传编制报告文件 → 通过

### 14. 最终审核
**操作人**：谢宝建（部门经理）

待办中心 → 审核任务 → 选择：
- **通过** → 进入材料归档
- **复核** → 编制人修改报告后重新提交
- **驳回** → 回到现场测评，项目经理重新发起（新一轮）

### 15. 材料归档
**操作人**：汤婷（归档员）+ 项目经理 + 销售 协助

材料归档 → 找到项目 → 逐项勾选卷内清单 → 上传扫描件 → 填写存放位置 → 提交归档

> 项目经理和销售也可以进入归档详情上传自己手里的材料扫描件

## 四、常用操作提示

| 场景 | 说明 |
|------|------|
| 收到通知 | 页面右上角铃铛图标查看，点击可跳转 |
| 被驳回 | 详情页顶部会显示红色驳回原因 |
| 待整改 | 测评实施列表会显示红色「待整改」标签 |
| 重新提交 | 修改测评成果后，在测评详情页点击「重新提交」 |
| 审核意见 | 所有审核节点的详情页都有「审核意见历史」可查看 |
| 合同组 | 同一中标项目的多个合同归组管理，列表展开可查看组内所有合同 |
| 合同文件 | 提交审核前必须上传合同文件和合同文件说明 |
| 系统明细 | 项目登记提交前必须完善所有系统明细的必填字段和备案证明 |
| 数据隔离 | 销售只能看到自己创建或作为跟单销售的合同和项目 |
