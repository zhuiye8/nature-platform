# 生产环境部署指南

> 最后更新：2026-04-09

## 一、服务器要求

- OS: Ubuntu 22.04+
- Docker + Docker Compose
- Node.js 20+
- pnpm 10+
- 最低配置: 2C4G

## 二、项目结构（服务器）

```
~/nature-platform/
├── docker/
│   ├── docker-prod.yml        # 生产 Docker Compose（自行维护）
│   └── docker.env             # Docker 环境变量
├── packages/
│   ├── server/                # NestJS 后端
│   └── web/                   # Vue 前端（构建后由 Nginx 托管）
├── scripts/
│   ├── seed.sql               # 种子数据（角色、权限、工作流等）
│   └── init-employees.sql     # 员工账号初始化（一次性）
├── .env                       # 后端环境变量
└── prod.yml                   # 生产 Docker Compose（可选位置）
```

## 三、首次部署

### 1. 克隆代码
```bash
git clone <仓库地址> ~/nature-platform
cd ~/nature-platform
```

### 2. 配置环境变量
```bash
cp .env.example .env
vi .env
```

关键配置项：
```env
# 数据库（端口与 docker-prod.yml 对应）
DATABASE_URL=postgresql://nature:<密码>@localhost:15432/nature

# Redis
REDIS_URL=redis://:<密码>@localhost:16379

# MinIO
MINIO_ENDPOINT=http://localhost:19000
MINIO_ACCESS_KEY=<与docker-prod.yml中MINIO_ROOT_USER一致>
MINIO_SECRET_KEY=<与docker-prod.yml中MINIO_ROOT_PASSWORD一致>

# JWT
JWT_SECRET=<生产用长随机字符串>

# 钉钉登录
DINGTALK_APP_KEY=<AppKey>
DINGTALK_APP_SECRET=<AppSecret>
DINGTALK_REDIRECT_URI=https://<你的域名>/dingtalk/callback
```

### 3. 启动 Docker 容器
```bash
cd docker
# 确保 docker-prod.yml 中已移除 schema.sql 挂载行
docker compose -f docker-prod.yml --env-file docker.env up -d
```

### 4. 安装依赖
```bash
cd ~/nature-platform
pnpm install
```

### 5. 数据库初始化
```bash
cd packages/server

# 执行迁移（创建所有表）
pnpm db:migrate

# 导入种子数据
docker exec -i nature-postgres psql -U nature -d nature < ../../scripts/seed.sql

# 导入员工账号（首次部署需要）
docker exec -i nature-postgres psql -U nature -d nature < ../../scripts/init-employees.sql
```

### 6. 构建前端
```bash
cd ~/nature-platform/packages/web
pnpm build
```

### 7. 配置后端服务（systemd）
```bash
cat > /etc/systemd/system/nature-api.service << 'EOF'
[Unit]
Description=Nature API Server
After=network.target docker.service

[Service]
Type=simple
User=root
WorkingDirectory=/root/nature-platform/packages/server
ExecStart=/usr/bin/node dist/main.js
Restart=on-failure
RestartSec=5
Environment=NODE_ENV=production

[Install]
WantedBy=multi-user.target
EOF

systemctl daemon-reload
systemctl enable nature-api
```

### 8. 构建后端并启动
```bash
cd ~/nature-platform/packages/server
pnpm build
systemctl start nature-api
```

### 9. 配置 Nginx（前端 + API 反向代理）
```nginx
server {
    listen 80;
    server_name <你的域名>;

    # 前端静态文件
    location / {
        root /root/nature-platform/packages/web/dist;
        try_files $uri $uri/ /index.html;
    }

    # 后端 API 代理
    location /api/ {
        proxy_pass http://127.0.0.1:3010/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        client_max_body_size 500M;
    }
}
```

### 10. 钉钉开放平台配置
- 登录 https://open.dingtalk.com/
- 应用回调地址：`https://<你的域名>/dingtalk/callback`
- 开通权限：`Contact.User.Read`

## 四、日常更新

```bash
cd ~/nature-platform
git pull

# 如果有数据库变更
cd packages/server
pnpm db:migrate

# 如果有新依赖
pnpm install

# 重新构建前端
cd ../web && pnpm build

# 重启后端
systemctl restart nature-api
```

## 五、数据库重建（仅紧急情况）

> ⚠️ 启用 Drizzle 迁移后，正常情况下不应该再删库重建

```bash
cd ~/nature-platform/docker
docker compose -f docker-prod.yml down
docker volume rm docker_nature_pgdata_prod
docker compose -f docker-prod.yml --env-file docker.env up -d
sleep 10

cd ../packages/server
pnpm db:migrate
docker exec -i nature-postgres psql -U nature -d nature < ../../scripts/seed.sql
docker exec -i nature-postgres psql -U nature -d nature < ../../scripts/init-employees.sql
systemctl restart nature-api
```

## 六、常用命令

| 操作 | 命令 |
|------|------|
| 查看后端状态 | `systemctl status nature-api` |
| 查看后端日志 | `journalctl -u nature-api -f` |
| 重启后端 | `systemctl restart nature-api` |
| 查看容器状态 | `docker ps` |
| 进入数据库 | `docker exec -it nature-postgres psql -U nature -d nature` |
| 数据库迁移 | `cd packages/server && pnpm db:migrate` |
| 执行种子数据 | `docker exec -i nature-postgres psql -U nature -d nature < scripts/seed.sql` |

| 服务 | 容器内端口 | 宿主机端口 |

| Redis | 6379 | 16379 |
| MinIO API | 9000 | 19000 |
| MinIO Console | 9001 | 19001 |
| NestJS API | 3010 | 3010 |
| Nginx | 80/443 | 80/443 |
