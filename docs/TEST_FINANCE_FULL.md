# 五、已知预期行为（不算 bug）

|---|---|---|
| 销售看不到别人的合同（开票/请款搜不到）| ✅ 预期 | 销售可见性设计 |

| chairman 角色管理无删除按钮 | ✅ 预期 | 系统内置角色保护，需先建非系统角色 |
| chairman 待办中心空 | ✅ 预期 | chairman 全只读，不参与日常待办 |
