### 测试 2 · 普通员工发起费用请款 - 报名费（用 lutao，5 分钟）

**目标**：验证三步选择 + 普通费用类型。

**步骤**：

1. 登录 `lutao` → 左侧菜单「财务管理 → 费用请款」（首次出现）
2. 点「新建费用请款」
3. **三步选择**：
   - 服务内容：等级保护测评
   - 合同：搜"扬州" → 选 #2（合同金额 ¥150,000）
   - 系统：勾选 1 个系统（金额展示，不可改）
4. **费用信息**：
   - 费用类型：报名费
   - 请款金额：`5000`
   - 发票金额：`5000`
   - 发票类型：专票
   - 发票税率：6%
5. **收款人**：
   - 收款人：张三
   - 开户行：建设银行XXX支行
   - 银行账号 - 试错：
     - ❌ 输入 `123` → 提示"应为 10-30 位数字"
     - ❌ 输入 `abc1234567890` → 同上
     - ✅ 输入 `6217001234567890` → 通过
6. 备注：随意
7. 点「保存草稿」→ ✅ 列表里出现 1 条 DRAFT
8. 编辑 → 上传一个附件（PDF 或图片）
9. 上传 `.exe` 文件 → ❌ 应被拦截 "可执行文件存在安全风险"
10. 「提交审核」→ ✅ 状态变 **SUBMITTED（部门审核中）**

**通过标准**：三步流畅，银行卡校验生效，附件黑名单生效。

## 附录 B · 主要变更清单

### 新增页面
- `/finance/expense` - 费用请款列表
- `/finance/expense/create` - 新建费用请款
- `/finance/expense/:id` - 费用请款详情/审核
- `/finance/expense/:id/edit` - 编辑费用请款
- `/finance/settlement` - 结算管理

### 数据库变更
- `finance_expense_request`（费用请款主表）
- `finance_expense_request_system`（请款-系统多对多）

### 角色权限
- 新增权限：`expense:request` / `expense:list` / `expense:dept_approve` / `expense:fin_approve` / `settlement:view`
- 权限分配：
  - 所有非超管补 `expense:request`
  - dept_manager / finance / chairman / super_admin 各自补对应权限

### 工作流
- `FIN_EXPENSE`（费用请款双层审核流程）
  - `FIN_EXPENSE_DEPT_REVIEW`（部门负责人审核）
  - `FIN_EXPENSE_FIN_REVIEW`（财务审核）

### 全局变更
- 所有列表默认每页 10 条（11 后端 DTO + 12 前端列表页）
